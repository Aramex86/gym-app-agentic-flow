Contract law04 / 11

Agents operate under constitutional law, not prompts.

  • §1NEVER git push · merge · commit · reset — by any agent, in any sandbox.Enforced by tool denial. Observed live: the developer asked for git and was refused, then handed the human a ready command.
  • §2FAIL is a stop, not an invitation to improvise. A failing gate halts the whole circle.The tester judged honestly and stopped the storybook circle; a human recipe fixed it in minutes.
  • §3Plans may not contain developer commit steps — commits belong to the tool after the human gate.Added after a plan shipped a self-committing developer (item 14, contract conflict).
  • §4Secrets live in env only — task files and prompts travel to the cloud as plain text.GitHub push protection once blocked a leaked key; the placeholder law was born the same evening.

The exam05 / 11

Every hop gets graded by a machine before a human sees it.

Machine gates run first — artifacts, verdicts, contract checks. Human gates only open what machines approve. The human designs the exam; the loop takes it.

$ machine gate: expected artifact docs/plans/…-report.md … OK
$ verdict scan … report starts with … PASS
$ contract scan … plan contains dev-commit steps … NONE
$ eval — exam suite across hops … scored
$ GATE committer: waiting for human … Y

Honest failure by design08 / 11

Three refusals in one day. All three were architecture working.

Refusal 1

Missing precondition

Plan §0 said: verify the storybook toolchain first; STOP if absent. It was absent. The tester stopped the circle instead of faking results.

→ Human recipe, toolchain restored, circle re-run
Refusal 2

Write denied

A law restoration had silently dropped Write from the tester's tools. The agent could not fake an artifact — it reported the loss.

→ Tool contract fixed, report recovered from denials
Refusal 3

Git denied

The developer finished nine files, tried to commit, was refused by the global law — and handed the human the exact commands instead.

→ Human committed after Y. Tests stayed green

The lesson is priced: an honest stop costs cents. A hidden burn costs dollars and trust.

Phase 410 / 11

The exam becomes the job.
